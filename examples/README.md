# Examples

This directory contains example code to help you get started with TRAE IDE.

## Python Example

Run the Python example:

```bash
python examples/python/hello.py
```

## JavaScript Example

Run the JavaScript example:

```bash
node examples/javascript/hello.js
```

## Creating Your Own Examples

Feel free to add more examples in this directory. TRAE IDE will apply the project rules defined in `.trae/rules/project_rules.md` when assisting you with code.
